        CSV format we accept

        A header row with a Date column, a description column (Description, Narration, Particulars…), and either one Amount column (negative = spent, or with Dr/Cr suffix) or separate Debit / Credit (or Withdrawal / Deposit) columns. Comma, semicolon, tab or pipe separated. Dates like 05/09/2026, 2026-09-05 or 05-Sep-2026 all work; 05/09 is read as day/month unless the file proves otherwise.
